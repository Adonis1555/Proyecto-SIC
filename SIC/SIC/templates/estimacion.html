Código Descripción Tipo DET FTR

Nota: Las ponderaciones por complejidad (baja/media/alta) de cada tipo PF se calculan según las tablas IFPUG usando DET y FTR. Este formulario está listo para que el cálculo lo haga el backend (Django) o, si prefieres, JS en el cliente.

Ajuste de Complejidad Técnica (VAF)

Valora cada factor entre 0 (no aplica) y 5 (influencia fuerte). Fórmula sugerida: VAF = 0.65 + 0.01 × ΣFI, con 14 factores.
